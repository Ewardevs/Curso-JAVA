## Programación Orientada a Objetos (POO) en Java

- **Fundamentos:** Principios de la POO (abstracción, encapsulación, herencia y polimorfismo).

- **Polimorfismo:** Diferencia entre sobrecarga, sobreescritura e inclusión.

- **Diseño de clases:** Comparación entre herencia y composición.

- **Elementos avanzados:** Clases abstractas, interfaces y enum.

- **Aplicación práctica:** Proyecto final integrando todos los conceptos.
